## 简介

Launcher Theme Enhancer 是一款 SJMCL 扩展，将此前三个独立插件整合为一个无缝体验，同时解决了三者同时开启时的冲突问题。

内置中英文切换按钮，可在设置面板中一键切换语言，无需安装不同语言版本。

不支持与 sjmcl-video-background、sjmcl-weather-effects、sjmcl-city-weather 等旧版独立插件共存，建议卸载旧插件后使用本整合版以获得最佳体验。

## 功能特色

### 🌤 城市天气
- 通过 Open-Meteo API 获取实时天气数据
- 覆盖全球 200+ 城市
- 相比旧版，天气响应更精准、过渡更平滑
- 新增“动态氛围”开关，可独立关闭天气渐变与图标动效，不影响查询和数据

### 🎬 动态视频背景
- 上传 MP4/WebM 视频文件作为启动器背景
- 修复了旧版动态背景会覆盖其他插件页面的问题
- 音量控制、播放/删除

### ✨ 粒子特效（21 种）

- 樱花飘落 — 粉色花瓣从左上方向右下方旋转、翻面飘落
- 萤火虫之夜 — 在深色夜色中缓慢漂浮、呼吸闪烁的暖色光点
- DNA 粒子流 — 多个青蓝与紫红短螺旋片段斜向漂移，以光点和淡横杆构成氛围
- 鬼影 — 半透明幽灵轮廓缓慢漂浮，带有微弱眼光
- 雨滴涟漪 — 淡淡的细雨线条与地面扩散椭圆涟漪
- 键盘光效 — 底部三层 RGB 辉光、四周弱光、上浮光点和向上柔和渐变的短光柱
- 附魔 — 浮动的附魔符文在空中飘浮
- 幽匿 — 循声守卫风格的幽匿粒子效果
- 冻结 — 冰雪霜冻覆盖整个界面
- 代码 — 矩阵风格的绿色代码雨
- 灰尘 — 空气中漂浮的细微尘埃
- 活力 — 充满生机的彩色光点
- 火焰 — 跳动的火焰粒子效果
- 雪 — 缓缓飘落的雪花
- 日落 — 暖色调的日落余晖
- 水下 — 水中的气泡与光影
- 极光 — 流动的极光带效果
- 雨 — 淅淅沥沥的雨滴
- 沙暴 — 漫天飞舞的沙尘
- 星空 — 闪烁的星辰夜空
- 落叶 — 随风飘落的叶子

### 🌐 语言切换
- 设置面板中一键切换中英文
- 不再需要下载不同语言版本

### 💾 状态记忆
- 自动记住粒子类型、强度和运行状态
- 视频内容保存在 IndexedDB 中，重新打开启动器后自动恢复
- 记住视频音量和暂停状态
- 系统阻止有声自动播放时，会先静音恢复，并在首次点击后恢复声音

### 🧱 隔离背景层
- 视频和粒子挂在主界面专用背景层中，不再覆盖其他扩展页面、弹窗或独立窗口
- 独立窗口默认不加载动态背景

### 🖱 鼠标效果
- 新增独立的“鼠标效果”首页卡片，与城市天气和主题粒子并列
- 卡片使用展开式效果选择器，并带有随当前效果变化的动态渐变线
- 支持光标星尘、彗尾轨迹、星芒轨迹、樱叶轨迹、雪花拖尾和数据残影
- 鼠标静止时不生成粒子，空闲时停止 Canvas 动画循环
- 支持独立开关和强度设置，并与主题粒子同时运行
- 默认关闭，可在首页卡片中启用

### 🎛 统一卡片交互
- 城市天气、主题增强和鼠标效果使用统一的标题图标、状态徽章与开关
- 关闭状态下强调线暂停流动，同时降低亮度和饱和度
- 主题增强的粒子开关只控制粒子，视频背景保持独立控制
- 主题强调线、选择框、滑块和百分比数字会跟随当前粒子配色
- 主题选择器支持展开、限高滚动、箭头旋转和选中反馈

### ⚙️ 设置界面
- 设置页采用与首页卡片一致的图标、状态徽章、动态光带和交互反馈
- 主题效果使用展开式选择器，箭头平滑旋转，列表限制高度并支持滚动
- 未选择视频时使用紧凑的选文件入口，不再占据大面积页面
- 天气、主题粒子和视频音量滑块使用统一的彩色样式
- 设置页与首页卡片实时同步开关、粒子类型、强度和语言状态

## 使用方法

1. 从 Releases 下载对应的 .sjmclx 文件
2. 打开 SJMCL → 设置 → 扩展管理 → 导入，插件支持选择文件导入和拖动导入
3. 启用即可

- 最低启动器版本: 1.1.3
